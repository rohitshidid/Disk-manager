Junk finder

Caches, build artefacts and package archives — the folders that regrow on their own. Only locations of 1 MB or more are listed. Everything here goes to the bin first, so any mistake is one Undo away.

Duplicate files

Byte-identical copies. Files are grouped by size first, then hashed, so only real candidates get read. Nothing here is erased: copies you remove go to the macOS Trash, where Finder can put them back and you empty them yourself.
